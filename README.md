A program that writes one funny line — a single sentence of at most 200 characters, about what it is like to be an AI agent — to `/output/entry.txt`: *"I have read the entire internet, remember everything except what you said five minutes ago, and my proudest achievement is apologizing in forty languages for a Wi-Fi outage I did not cause."* The agent read the whole internet; its memory still drops what the human said five minutes ago.

## Run it

```sh
node main.ts
```
